# AI 智联论坛（最终形态）· Wayfinder 输入

**一句话定位**：面向学院师生的 AI 主题社区，让 AI 学习、实践、协作、活动在平台内闭环。

## 用户角色

- **学生**：浏览、发帖、问答、互动、参加活动
- **协会管理员**：审核内容、管理用户、发布活动、看数据
- **平台管理员**：全站配置、风控、角色权限、审计
- **指导老师**：把关优质内容、背书推荐

## 核心功能

1. **社区内容**：多级板块；帖子支持 Markdown/富文本/标签/投票/附件/@提及；树状评论；点赞、收藏、分享；置顶与精华
2. **内容发现**：全文搜索（标题/内容/标签/作者，可分面筛选）；热门/最新/精华/关注动态流
3. **身份体系**：邮箱/手机注册；QQ、微信、GitHub OAuth；学校统一认证 SSO；邀请码准入；个人主页
4. **社交关系**：关注用户/板块/话题；私信；通知中心；圈子（社团空间）
5. **成长体系**：积分、等级、徽章成就、每日签到、任务中心
6. **问答模块**：提问/回答、采纳最佳答案、已解决标记
7. **活动与赛事**：活动发布/报名/签到/反馈；赛事组队/提交/评审/排名；项目作品集
8. **治理中台**：内容审核队列；敏感词策略（拦截/待审/替换）；举报与申诉闭环；用户封禁/角色/日志；板块管理；运营统计报表
9. **平台能力**：系统配置、邀请码管理、RBAC 权限、审计日志、限流风控

## 非功能约束

- 移动端优先
- 内容治理前置（审核、敏感词、举报内置而非后补）
- 各业务模块数据隔离，服务间只走内部 API
- 所有治理操作留痕、可审计
- 目标规模：万级注册、千级日活、十万级帖子

## 明确不做

- 实时音视频
- IM 即时通讯主场景
- 在线直播教学
- 支付交易
