| 编号 | 决策问题 | 定案 | 依据 |
|---|---|---|---|
| D1 | 默认展示形态 | **默认只显示一级评论**；一级有回复 → 「展开 N 条回复」，**N = 该分支全部后代**（含所有层级） | ticket #47「已与用户确认」段 + 用户确认（2026-08-21） |

| D4 | 回复后体验 | 提交成功后**自动展开所在分支**并**滚动定位 + 高亮**新回复（`accent-soft` 渐隐 1.6s） | 用户确认（2026-08-21）；高亮时长取 IA §5.2 口径 |
| D5 | 旧折叠逻辑 | 现有「同级超 3 条折叠」**整体移除**（被深度截断取代） | 用户确认（2026-08-21） |
| D6 | 评论计数 | 帖子头「评论 N」**不变**（仍含所有层级） | ticket #47「已与用户确认」段（2026-08-21） |
